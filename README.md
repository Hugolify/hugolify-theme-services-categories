# hugolify-theme-services-categories

## Install

Edit `config/_default/module.yaml` to install the `hugolify-theme-services-categories` module:

### V2

```yml
imports:
  - path: github.com/hugolify/hugolify-theme-services-categories/v2
  - path: github.com/hugolify/hugolify-theme-services/v2 # required
  - path: github.com/hugolify/hugolify-theme/v2 # required
```

### V1

```yml
imports:
  - path: github.com/hugolify/hugolify-theme-services-categories
  - path: github.com/hugolify/hugolify-theme-services # required
  - path: github.com/hugolify/hugolify-theme # required
```
